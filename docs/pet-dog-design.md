# 🐶 팀 강아지 키우기 — 설계 (2026-11-25, 승인 대기)

홈 2행 3칸(연상퀴즈 자리)에 들어가는 팀 공용 강아지. 두 달(60일) 프로젝트.

## 확정된 방향 (사용자 선택, 2026-11-25)
| 항목 | 결정 |
|---|---|
| 기간 | 1~30일 성장(외형 변화) + 31~60일 쌓기(옷·소품·개인기) → 60일째 졸업, 다음 동물 |
| 시간 이벤트 | 밥·똥 = 팀 공용 선착순 / 간식·놀아주기·쓰다듬기 = 사람마다 하루 횟수 |
| 산책 | 사람마다 하는 짧은 미니게임. 실패하면 친밀도 실패 + 속상한 강아지 표정을 재밌게 |
| 방치 | 가출 이벤트. 정성을 보여주는 반복 행동(노가다)을 팀이 채우면 돌아옴 |

## 0. 연상퀴즈 끄기 (없애지 않음)
- `team_log_settings`에 `quiz_enabled` 키(기본 true). 팀장만 바꿈(기존 `/api/team-settings` 경로).
- off면 숨김: 홈 퀴즈 카드, `QuizTurnBanner`, 상단 "내 차례" 버튼 2곳, 평일 10시 자동 시작(`useQuizAutomation` enabled=false), 퀴즈 메뉴 진입.
- 퀴즈 테이블·기록은 그대로. 다시 켜면 원래대로.

## 1. 하루 흐름 (서울 시간, 평일)
| 시간 | 팀 공용(선착순, 먼저 한 1명만 점수) | 친밀도 |
|---|---|---|
| 09~11시 | 🍚 아침밥 | +5 |
| 12~14시 | 🍚 점심밥 | +5 |
| 17~19시 | 🍚 저녁밥 | +5 |
| 밥 먹고 1시간 뒤 | 💩 똥 생김 → 치우기 | +3 |

| 개인 행동(사람마다) | 하루 횟수 | 친밀도 |
|---|---|---|
| 🦴 간식 | 2 | +2 |
| 🎾 놀아주기 | 3 | +2 |
| ✋ 쓰다듬기 | 5 | +1 |
| 🦮 산책(미니게임) | 1(실패 시 1번 더) | 성공 +6 / 실패 +1 |
| 🎓 훈련(31일~) | 3 | +2, 개인기 진척 |

- 시간 판정·횟수 제한은 전부 DB 함수가 한다(화면 조작으로 우회 불가, 서류탑과 같은 방식).
- 주말: "펫시터가 돌봐요" — 밥·똥 없음, 나이는 그대로 먹음.

## 2. 성장 (1~30일)
- 나이 = 태어난 날부터 지난 날짜 수(가출 기간은 빼고).
- 단계: 1~5일 갓난 새끼 · 6~12일 아기 · 13~20일 어린이 · 21~29일 청소년 · 30일 성견.
- 단계 안에서도 날마다 몸 크기·귀·꼬리 비율이 조금씩 바뀜(SVG로 직접 그림, 이미지 파일 없음).
- 표정: 기본 / 배고픔(밥 시간인데 아직) / 똥 쌓임 / 신남(방금 놀아줌) / 속상(산책 실패) / 졸림(퇴근 뒤).

## 3. 산책 미니게임 (약 20초)
- 강아지가 길을 걷는데 고양이·비둘기·다른 개·전봇대·떨어진 음식이 나옴 → 방향키(휴대폰은 조이스틱)·클릭으로 목줄을 당겨 버팀.
- 목줄 긴장 게이지가 끝까지 차면 실패: 고양이 쫓아 달려갔다가 진흙 묻히고 돌아와서 귀 처진 표정 + 한 줄 대사("…미안해요 멍").
- 길에 똥을 싸면 봉투로 줍기 보너스.

## 4. 가출과 귀가
- 조건: 평일 기준 이틀 연속 밥을 한 번도 안 줌 → 다음날 아침 "가출했어요" 쪽지만 남음.
- 귀가: 팀 전원 합산 "이름 부르며 찾기" 300번(1번 = 버튼 누르기 + 짧은 대기, 사람당 하루 60번까지). 다 채우면 돌아와서 가장 많이 찾은 사람에게 먼저 달려감.
- 가출 동안 나이는 멈춤.

## 5. 쌓기 (31~60일)
- 팀 친밀도 합계가 구간을 넘을 때마다 옷·소품 해금(목도리, 모자, 선글라스, 넥타이, 사원증, 산타옷 …). 해금된 것 중 하나씩 입히기, 누가 입혔는지 표시.
- 개인기: 훈련 누적으로 배움(앉아 → 손 → 엎드려 → 빵야 → 한 바퀴 → 하이파이브 → 사원증 물어오기). 배운 개인기는 홈 박스에서 가끔 저절로 함.
- 사람별 친밀도 1위 = "제일 좋아하는 사람" 표시, 홈 박스에서 그 사람이 들어오면 꼬리 더 흔듦.
- 60일째: 졸업 앨범(단계별 모습·기록·친밀도 순위) 남기고 다음 동물 선택.

## 6. DB (초안)
- `pets`: id, species, name, born_on, status(active/runaway/graduated), runaway_since, paused_days, outfit, created_at
- `pet_actions`: id, pet_id, member_id, kind, slot_key, result, points, created_at
  - 공용 선착순은 `(pet_id, kind, slot_key)` 유일 인덱스로 보장
- `pet_unlocks`: pet_id, item_key, unlocked_at / `pet_tricks`: pet_id, trick_key, progress, learned_at
- 쓰기는 전부 RPC(`pet_act(kind)` 등). 실시간: `pet_actions`·`pets`를 `supabase_realtime`에 추가.

## STEP 계획 (STEP마다 로컬 확인 → 승인 → 다음)

2. DB 테이블·함수 + 직접 실행·롤백 시험
3. 홈 카드: 강아지 SVG 5단계·표정, 밥·똥·간식·놀아주기·쓰다듬기, 친밀도 순위
4. 산책 미니게임
5. 가출·찾기
6. 31~60일 옷·개인기·졸업 앨범
